## Что это

**RetroView** — программа для Windows, которая захватывает экран или отдельное окно и показывает его **как старый телевизор**. CRT-эффекты, шум, сканлайны, VHS-дрожание — всё как в 80-х.

Работает в реальном времени. Можно использовать:
- Для **ретро-стримов** — наложить эффект на игру
- Для **записи видео** — сохранить MP4 с эффектами
- Для **скриншотов** — снимок экрана «как из старого ТВ»

---

## Возможности

- **Захват экрана** — весь экран, половина, центр
- **Захват окна** — отдельное приложение (F2 / F3)
- **Переключение мониторов** — M / Shift+M
- **CRT-эффекты** — сканлайны, шум, виньетка, свечение
- **VHS-эффекты** — дрожание, полосы, хроматическая аберрация
- **Barrel distortion** — искривление картинки
- **4 пресета** — VHS 80-х, CRT Trinitron, Советский ТВ, OLED
- **Запись MP4** — R
- **Снимки PNG** — S
- **Low-latency** — минимум задержки для игр
- **Трей** — сворачивается в трей
- **Автосохранение настроек** — F6

## Установка

### Вариант 1 — готовый exe

Скачай `RetroView.exe` из раздела **Releases** и запусти. Установка не нужна — это **портативная** версия.

### Вариант 2 — из исходников

```bash
pip install pygame-ce mss numpy pillow opencv-python dxcam pystray
python RetroView.py
```

**Требования:**
- Windows 10/11 (x64)
- **Visual C++ Redistributable 2015–2022** — [скачать](https://aka.ms/vs/17/release/vc_redist.x64.exe)
- Python 3.10+ (для запуска из исходников)

## Управление

| Клавиша | Что делает |
|---|---|
| **F2** | Список окон |
| **F3** | Захват окна в фокусе (2 сек) |
| **M** | Следующий монитор |
| **Shift+M** | Предыдущий монитор |
| **1** | Весь экран |
| **2** | Левая половина |
| **3** | Правая половина |
| **4** | Центр |
| **Q** | Качество (НИЗКОЕ → УЛЬТРА) |
| **E** | Пресет эффектов |
| **L** | Low-latency вкл/выкл |
| **C** | CRT вкл/выкл |
| **N** | Шум |
| **[** | Уменьшить сканлайны |
| **]** | Увеличить сканлайны |
| **-** | Уменьшить яркость |
| **=** | Увеличить яркость |
| **G** | Глитч |
| **T** | Снег (нет сигнала) |
| **P** | Питание вкл/выкл |
| **R** | Начать/остановить запись |
| **S** | Снимок PNG |
| **U** | Курсор вкл/выкл |
| **Tab** | Скрыть/показать HUD |
| **F1** | Помощь |
| **F6** | Сохранить настройки |
| **Space** | Пауза |
| **F11** | Полный экран |
| **Ctrl+Shift+Tab** | Полный экран (глобально) |
| **Esc** | Выход |

## Файлы

После запуска создаются:

- `rv_settings.json` — настройки (качество, эффекты, монитор, окно)
- `rv_snapshots/` — снимки PNG
- `rv_recordings/` — записи MP4
