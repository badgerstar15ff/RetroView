ЧТО ЭТО
=======
RetroView захватывает экран или отдельное окно и показывает
его как старый телевизор — с CRT-эффектами, шумом, сканлайнами.

Можно использовать для:
  - ретро-стримов (наложить эффект на игру)
  - записи видео (MP4 с эффектами)
  - скриншотов (снимок "как из старого ТВ")


УСТАНОВКА
=========
1. Распакуй RetroView.exe в любую папку
2. Запусти RetroView.exe
3. Готово — установка не требуется

ТРЕБОВАНИЯ:
  - Windows 10/11 (x64)
  - Visual C++ Redistributable 2015-2022
    (если не запускается — скачай:
     https://aka.ms/vs/17/release/vc_redist.x64.exe)


УПРАВЛЕНИЕ
==========
F2  - список окон
F3  - захват окна в фокусе
M   - следующий монитор
Shift+M - предыдущий монитор
1-4 - зоны экрана: весь / лево / право / центр
Q   - качество (НИЗКОЕ / СРЕДНЕЕ / ВЫСОКОЕ / УЛЬТРА)
E   - пресет эффектов (VHS / Trinitron / Советский / OLED)
L   - low-latency (меньше задержка)
C   - CRT вкл/выкл
N   - шум
[ ] - сканлайны
- = - яркость
G   - глитч
T   - снег (нет сигнала)
P   - питание вкл/выкл
R   - запись MP4
S   - снимок PNG
U   - курсор вкл/выкл
Tab - скрыть/показать HUD
F1  - помощь
F6  - сохранить настройки
Space - пауза
F11 - полный экран
Esc - выход


ФАЙЛЫ
=====
rv_settings.json   - настройки
rv_snapshots/      - снимки PNG
rv_recordings/     - записи MP4


ТРЕЙ
====
При закрытии окна программа сворачивается в трей.
Оттуда можно:
  - Показать
  - Запись R
  - Выход
